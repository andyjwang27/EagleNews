# EagleNews
Eagle News is an announcement-based app that will be used at Stratford Academy. It's purpose is to improve communication across administration and the student body. It includes features such as a home page, to-do list, calendar, links, and admin only page.

**Platforms:**

Eagle News is programmed in both Apple SwiftUI and Android Kotlin languages. The Apple version has been submitted and approved while the Android is still being updated from Version 1.0.

**Features:**
  - User login/registration using school provided student Google accounts
  - User specific roles for announcements
  - Home page with announcements
  - Links page with links
  - To-do list
  - Calendar with personal and group events
  - Profile page with information, name change options, and account deletion
  - Admin only page to create or delete announcements, links, and assign or remove user roles

**Running the Applications:**

  iOS:

  Open the XCode project and run using the native iOS simulator on any iPhone device.

  Android:

  Open the Android project and run using the native Android emulator on any Android phone.
